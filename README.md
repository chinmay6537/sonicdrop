# SonicDrop

Send photos between two devices using **only sound**: no Wi-Fi, no Bluetooth,
no cables. One device plays the data through its speaker and the other listens
through its microphone.

Status: **design phase.** See [IDEATION.md](IDEATION.md) for the full design:
OFDM modem, chirp sync, noise-aware tone masking, fountain codes, and the
handshake protocol.
